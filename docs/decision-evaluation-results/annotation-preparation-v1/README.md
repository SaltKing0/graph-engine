## Delivered artifacts and exposure

`packet.json.gz` and `blank-form.json.gz` losslessly compress the exact UTF-8
JSON generated by the documented exporter. `manifest.json` hashes the
**uncompressed** packet/form/report. `stored-files.json` hashes the stored
compressed artifacts and binds the preparation to the handbook, original
normative contract and starting main revision. It does not bind later validation
logs or this README, and is not a final-corpus freeze or human signature.

There are eight chronological development events, 27 eligible pairs and 15
distinct source records, all already exposed. The packets retain exact bytes,
source revisions, original excerpt/patch provenance, timestamps, MIT notices
and duplicate measurement lineages. Inputs use documented-action
reconstructions; they are not historical human reviews. Draft conditions,
dependencies, expected paths, labels and engine outputs are excluded. No
evaluation-source bytes or label files are opened by this exporter.

The implementing agent has read the original protocol, original development
sources and saved aggregate diagnostic evidence. Existing full-suite regressions
also exercise old exposed corpus fixtures. None of these cases may be called
fresh independent evidence. No new successor final source, label or answer key
has been supplied or inspected in this work. The public repository and these
hashes provide no ACL separation for future reserved data.

`preparation-report.json` explicitly has `acceptance_complete=false`, unknown
independently reviewed development counts and final coverage 0 positive pairs,
0 negative pairs and 0 inconclusive cases. Null reviewer identities, outcomes,
disagreements and calibration fields are unfinished work, not fabricated

## Reproduction and artifact verification

From the repository root, using Python 3.12.14 and the development environment:

```bash
.venv/bin/python -m tools.decision_benchmark.annotation_packets --output /tmp/issue90-development-v1
.venv/bin/python - <<'PY'
import gzip, json
from pathlib import Path
from tools.decision_benchmark.corpus import canonical, digest
from tools.decision_benchmark.annotation_packets import validate_packet
saved = Path('docs/decision-evaluation-results/annotation-preparation-v1')
generated = Path('/tmp/issue90-development-v1')
stored = json.loads((saved / 'stored-files.json').read_bytes())
assert digest(canonical(stored['files'])) == stored['sha256']
for name, sha in stored['files'].items():
    assert digest((saved / name).read_bytes()) == sha
for name, key in [('docs/decision-annotation-handbook.md', 'handbook_sha256'),
                  ('docs/decision-memory-v1.md', 'contract_sha256')]:
    assert digest(Path(name).read_bytes()) == stored[key]
manifest = json.loads((saved / 'manifest.json').read_bytes())
assert digest(canonical(manifest['files'])) == manifest['sha256']
for name, sha in manifest['files'].items():
    path = saved / name
    raw = path.read_bytes() if path.exists() else gzip.decompress((saved / (name + '.gz')).read_bytes())
    assert digest(raw) == sha
    assert raw == (generated / name).read_bytes()
assert (saved / 'manifest.json').read_bytes() == (generated / 'manifest.json').read_bytes()
packet = json.loads(gzip.decompress((saved / 'packet.json.gz').read_bytes()))
assert validate_packet(packet)['eligible_pairs'] == 27
logs = saved / 'validation'
log_manifest = json.loads((logs / 'files.json').read_bytes())
assert digest(canonical(log_manifest['files'])) == log_manifest['sha256']
for name, sha in log_manifest['files'].items():
    assert digest((logs / name).read_bytes()) == sha
identity = json.loads((logs / 'run-identity.json').read_bytes())
for name, sha in identity['code_files'].items():
    assert digest(Path(name).read_bytes()) == sha
print('Stored bytes, decompressed hashes, rubric/contract and regenerated artifacts match; acceptance remains incomplete.')
PY
```
